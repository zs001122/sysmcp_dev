# ADR-007：BIZ-T100 常驻内部模拟测试服务

日期：2026-09-29。决定：按用户明确授权，提供可持续调用的内部开发测试服务；身份、映射、服务 key 和业务上游全部为合成或模拟。本文不声明真实 T100、真实个人身份或 GOV 发布通过。

## 1. 目的与范围

已有一次性直连检查会在完成后关闭端口，不能满足用户持续连接并自行调用的需要。本次在 `projects/biz-t100/scripts/internal_test.py` 增加本地测试装配，复用当前产品查询/重置客户端、授权、工厂及 SQLite 审计，保留两个常驻本机 MCP 服务。

这是 BIZ 项目的开发工具，不增加 HTTP 登录、IAM、通用账号平台或新的上游代理。它不读取旧环境、真实员工名单或真实服务凭据，不联系真实业务接口，也不登记到 GOV。操作说明见 [internal-test](../projects/biz-t100/docs/internal-test.md)。

## 2. 决定

| 边界 | 本次选择 |
|---|---|
| 启动单元 | 查询与重置使用各自产品工厂、独立端口与单 worker，默认分别为 8766/8767；绑定 127.0.0.1，只能本机连接，可显式改用其他空闲端口 |
| 命令 | 本地 CLI 提供 init、token、serve、call、status、check；status 核对服务就绪，check 核对报文计数及审计，不提供网络签发或登录接口 |
| 临时签发 | 初始化时独立生成运行时签名私钥；token 命令本地签发，验证端只读取公钥并使用原生 AuthProvider 验签 |
| 身份契约 | 明确模拟 issuer、resource audience、subject、client、exp 与 scope；读/重置客户端与 scope 分开，不使用共享 API Key 代替个人 token |
| 固定合成人员 | user-a → E001/LOGIN-A，user-b → E002/LOGIN-B；另有停用与未映射负例，不表示任何真实员工 |
| 上游 | 显式 MockTransport 捕获真实产品客户端构造的报文，核对企业与授权目标，返回合成数据/ACK；不开放真实 URL 切换 |
| 持久状态 | 产品 SQLite 查询审计与重置操作库分别持久保存；模拟上游只输出去敏请求计数及必要关联，不输出 key、token 或原始业务响应 |
| 运行目录 | 默认 `projects/biz-t100/.runtime/internal-test`，私有目录 0700、文件 0600；init 幂等，不覆盖已有私钥或审计 |
| 秘密输出 | 签名私钥、合成服务 key 和 token 都不进入源码、产品 wheel、聊天或 CLI 原文；token 写入 0600 文件 |

服务维持运行直到用户或本轮启动方明确停止，不把一次健康响应当作长期托管保证。关闭采用对应前台进程 Ctrl-C，或对已核实的本次进程 PID 做正常终止；保留运行目录以便继续核对审计和拒重。

## 3. 与既有身份和写操作边界的关系

[身份设计 §4.1](可信个人身份与本人映射设计.md) 禁止模拟身份执行真实写操作，该约束保持有效。本次重置使用合成人员、合成服务 key 与内存模拟上游，不触及任何真实账号或密码；写入的只有本地测试操作记录，因此不构成对真实写限制的例外或放宽。

[ADR-006](架构决策-006-T100本人密码重置.md) 的本人 scope、默认关闭许可、独立账号绑定、显式确认、耐久拒重和未知双目标锁继续由产品代码执行。测试装配只在自己的合成策略中明确允许所需测试对象；不会放宽产品默认许可，也不改变重置客户端默认真实传输未就绪的行为。模拟 ACK 仍仅为 upstream_acknowledged，不代表真实密码已生效或交付。

当前产品依赖方向保持为脚本调用产品公开接口，产品源码不得导入 scripts/tests。AuthProvider、access、reader/resetter 与存储通过既有工厂显式注入。将来外部身份或真实上游实现就绪后，另行装配这些边界并完成相应验收，不改写身份授权用例，也不承诺本脚本已有某个真实来源切换参数。

## 4. 验证与状态口径

内部测试至少验证：两个服务独立暴露工具；原生验签；A/B 各自目标与读写 scope 隔离；停用/未映射前置拒绝且上游计数不增；重置同 ID 拒重和双目标锁；状态/事件与实际模拟请求计数可核对；停止再启动后原审计与拒重状态保留。init 再次执行不得轮换私钥或抹除证据，输出不得泄露秘密。

本次只使用 `internal-simulated` 描述运行环境；通过的代码契约测试可记 `biz-validated`。常驻监听、模拟签名与本地查询/重置成功均不能记为真实身份通过、business-validated 或 published。协议记录实际协商版本，不把本机直连等同 MetaMCP 两跳 Profile 验收。

真实只读接入仍按已授权的模拟签发者只读阶段流程另行装配；真实密码重置仍等待专用接口或已验证的无创建/启用/权限副作用契约、真实身份与账号归属及密码交付验收。内部模拟服务不关闭这些缺口。
