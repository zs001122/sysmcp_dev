# ADR-005：T100 测试接入与运行准备

日期：2026-09-29。状态：已采纳；运行准备完成离线验证，真实个人身份、业务与 GOV 发布未验收。

## 1. 已确认事实

用户指定 `/data/projects/account_mt` 为补充来源，并明确继续使用其旧 HTTP 测试入口、尚未接入个人身份来源。环境选择已经明确，不再要求用户重复选择；T100 服务管理员执行模式继续按 ADR-003 执行。

来源的报文、模糊查询和历史错误 key 放行记录见 [RU-002](reuse/RU-002-account-mt运行资料.md)。历史记录不等于本轮现场测试，服务管理员身份也不等于原接口确实检查 key。当前不得宣称服务认证、两员工本人授权或网关身份已经通过。

## 2. 显式测试传输

T100Config 新增 `transport_profile`，默认 `https`，保持原有 HTTPS 校验。只有显式选择 `http-test` 才接受 HTTP，且目标必须是 RFC1918 私网 IPv4 字面量。禁止 hostname、loopback、link-local、公网、URL 凭据、查询参数、fragment 和重定向，不自动降级或读取环境代理。

这是一项对用户已确认旧测试环境的限定适配，不提供加密，也不证明私网请求或服务 key 具有可信认证。真实地址和企业号放服务侧受控配置；仓库示例仍为 HTTPS 占位配置，不预置现网目标。正式发布前须取得符合发布环境要求的传输与认证证据；测试 Profile 不能冒充正式接入已验收。

保留完整工号查询以及“恰好一条且工号一致”的返回约束。原接口支持模糊查询时，多条结果直接拒绝，不取第一条、不批量过滤，不扩展为任意员工查询。

## 3. 运行装配

业务运行配置、代码、秘密和审计均保留在 BIZ-T100。新增严格 RuntimeConfig、私密配置加载、无业务 I/O 的本地检查，以及要求显式 AuthProvider 的应用工厂。复用原有授权、客户端和查询记录，不复制旧运行器、不建设新 IAM 或 HTTP 代理。

构造不监听、不联网、不读取 key。生命周期启动检查失败即拒绝；成功时准备独占 SQLite，但不制造业务事件。原生 MCP 生命周期由运行工厂托管，单进程限制在途 MCP 请求，超限 HTTP 503，不触发业务调用。健康端点仅表示本地状态，不证明上游连通、身份撤销服务健康或业务授权。

公开运维命令只提供 `check-config` 和 `pending`。没有选定、验证真实 AuthProvider 时，不生成携带测试身份的运行入口，不用共享 API Token、姓名、工具参数或 MetaMCP API Key替代个人身份。

## 4. 离线闭环与审计事实

用户进一步明确：开发阶段不依赖真实业务服务器；以合成签名身份、受控唯一映射和模拟上游验证身份→employee_no→工具许可→管理员key→实际请求→返回校验→审计。当前实现选择issuer+subject受控映射作为员工号唯一来源；即使令牌带签名employee_no也不自动启用另一来源。测试按enterprise_id+employee_no判断，姓名仅展示。

为区分派发前拒绝和调用后撤权，终态增加upstream_attempted，记录是否已进入EmployeeReader调用；它不证明网络送达，模拟上游实际捕获另证明请求数。SQLite Schema v2绑定固定企业/工具，并随事件保存其上下文。拒写v1，不执行真实数据迁移；外部QueryJournal实现同步新增关键字。未决记录仍可能已经调用，不能自动重放。

完整离线矩阵通过即可记biz-validated，不等待真实IdP。business-validated与published仍分别取证，见 [离线验收矩阵](../projects/biz-t100/docs/offline-acceptance.md)。

## 5. 证据与剩余条件

v0.3 保持现有工具名称、输入输出与本人授权语义；新增兼容配置与运行接口。验证见 [运行准备验证](../projects/biz-t100/VALIDATION-runtime.md)，运维见 [运行说明](../projects/biz-t100/docs/operations.md)。

真实闭环仍须接入可信个人身份与两员工受控映射，由接口维护方提供当前专用 key 交付及可验证的上游认证/错误契约，并完成直连与 GOV 两跳验收。新增配置或本地 ready 成功均不能提升 `business-validated` 或 `published`。

2026-09-29 用户补充：真实身份来源到位前，身份主体以受控模拟签发者临时替代（走完整 AuthProvider 验签路径，非 Header/参数/共享 token）。§3 中"没有选定、验证真实 AuthProvider 时不生成携带测试身份的运行入口"的前提据此修订：运行入口可按模拟签发者装配，但其证据级别、禁止事项与替换路径见 [可信个人身份与本人映射设计](可信个人身份与本人映射设计.md) §4.1；模拟身份闭环不记为真实身份通过。
